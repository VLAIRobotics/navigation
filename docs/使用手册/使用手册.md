# Nav2 工作区使用手册

本手册提供从环境安装到导航操作的详细步骤。按表格选择要完成的任务；第一次使用按“准备设备 → 检查传感器 → 建图（按需）→ 导航”进行。

## 第一次使用

| 顺序 | 操作 |
| --- | --- |
| 1. 准备 | 按[环境准备与终端操作](环境准备与终端操作.md)安装依赖并编译工作区，再按[MID360 网络配置](设备接入与启动配置.md#mid360-network)完成接线和网口设置。 |
| 2. 检查 | 按[传感器检查流程](传感器建图与校准.md#sensor-check)启动驱动，确认 `/livox/lidar`、`/livox/imu` 和 `/Odometry` 持续有数据。 |
| 3. 建图（按需） | 需要保存场地地图时，按[建图与保存地图](传感器建图与校准.md#mapping-save)生成 PCD。 |
| 4. 导航 | 选择[无图导航](Nav2导航与RViz操作.md#no-map-navigation)或[地图导航](Nav2导航与RViz操作.md#map-navigation)。首次只验证定位和规划时，使用 `enable_chassis:=false`。 |

电脑网卡地址和雷达 IP 请按现场确认；`192.168.1.5`（电脑）与 `192.168.1.194`（MID360）只是当前配置示例。

## 操作约定

| 项目 | 说明 |
| --- | --- |
| 仓库路径 | 示例路径为 `/home/nvidia/l1_navigation`；仓库放在其他位置时，请替换命令中的路径。 |
| ROS 环境 | 启动脚本会加载环境；手动运行 `ros2` 命令前，每个新终端都要加载 `/opt/ros/humble` 和工作区 `install` 环境。 |
| 流程切换 | 同一时间只运行一条传感器、建图或导航主流程；切换前在启动终端按 `Ctrl+C` 并等待退出。 |
| 真实底盘 | 只有 CAN、急停、速度标定和测试区域都经硬件负责人确认后，才启用真实底盘。 |
